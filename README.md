
# 🔐 Password Cracking Labs

Hands-on password security labs completed as part of my Cybersecurity & Ethical Hacking learning journey with NetworkWalks Academy.

This repository documents practical exercises involving password hash extraction, dictionary attacks, and password recovery using different tools.

## 📚 Labs Completed

### Lab 01: Password Cracking with John the Ripper

- Tool: John the Ripper (Jumbo) + Johnny GUI
- Extracted a password hash from an encrypted PDF.
- Loaded the hash into Johnny.
- Performed a dictionary attack.
- Recovered the password and unlocked the PDF.
- Captured the lab flag.

### Lab 02: Password Cracking with NetworkWalks Tools

- Tool: NetworkWalks Hash Calculator & Password Cracker
- Extracted the hash from an encrypted PDF.
- Used the built-in wordlist for a dictionary attack.
- Recovered the password.
- Unlocked the PDF and captured the lab flag.

## 💡 Key Takeaways

- Weak and commonly used passwords can be recovered through dictionary attacks.
- Password hashes can be tested against guessed passwords without directly decrypting the hash.
- Password length, uniqueness, and complexity play an important role in security.
- Strong passphrases help resist dictionary-based attacks.

## 🎯 Objective

To understand how password cracking works in a controlled lab environment and explore the importance of strong password practices through hands-on exercises.
